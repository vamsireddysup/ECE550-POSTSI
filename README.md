# ECE550: Post-Silicon Validation

Post-silicon validation project for ECE 550, covering Design for Test (DFX) and Test Access Port (TAP) verification methodologies.

## Project Structure

```
ECE550-POSTSI/
├── PostSiProject-P1/              # Project 1 deliverables and source files
│   └── PostSiProject/             # Main project directory
├── proj1_rel/                     # Project 1 release package
├── PostSiliconValidation_DFX.pdf  # DFX lecture/reference document
└── PostSiliconValidation_TAP.pdf  # TAP lecture/reference document
```

## Topics Covered

- Post-silicon validation methodologies
- Design for Testability (DFX) — built-in self-test, scan chains
- Test Access Port (TAP) — JTAG IEEE 1149.1 protocol
- Boundary scan testing and silicon debug

## Tools

- JTAG boundary scan analysis
- Post-silicon debug infrastructure
